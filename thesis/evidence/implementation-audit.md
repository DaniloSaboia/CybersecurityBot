## Critical qualifications retained in the chapter

1. **Hosted versus local:** local models, local database, and local authentication are independent. Compose and base application profile fallbacks differ. No deployed environment is certified by this audit.
2. **Governance versus content:** immutable revision creation status is not current workflow approval. Article text and vector rows do not grant access.
3. **History versus access:** immutable history survives state changes, but the normal evidence view requires current approval/readability. A retained citation can become unavailable.
4. **Producer trust versus review:** trusted connector/seed initialization is public and approved by policy; it is not independent human verification of upstream facts.
5. **No evidence versus no provider calls:** the literal retrieval path can embed the question before discovering no usable evidence. Comments saying “no provider call of any kind” must not override this executable call order.
6. **RRF ordering versus reported scores:** fusion orders candidates, but retained row scores remain branch scores. No confidence interpretation is warranted.
7. **SSE versus token latency:** the final authorization-safe path buffers provider output before emitting safe events. No first-token latency result was collected.
8. **Evidence identity versus truth:** valid references bind retained content; they do not prove entailment or guarantee that bounded prompt context included every referenced character.
9. **Durability versus exactly once:** retained sources and fenced commits do not prevent all repeated provider work.
10. **Graph scope:** minimal immutable entity/edge assertion store, explicitly not graph traversal, GraphRAG, or automatic multi-hop inference.
11. **Audit immutability versus completeness:** stored events resist ordinary mutation, while event insertion is deliberately best-effort.
12. **Tests versus experiments:** no test count or passing status is asserted here; code tests are not retrieval-effectiveness or analyst-productivity results.
